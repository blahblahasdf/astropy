# Hello World Examples

This directory contains simple "Hello World" example implementations demonstrating different ways to use Astropy's project structure.

## Simple Console Example
The basic console example can be run with:
```python
python main.py
```

This will print "Hello, World!" to the console.

## Flask Web Application
A Flask-based web application example is also provided. To run it:
```python
python flask_app.py
```

This will start a development server at `http://localhost:5000` that returns "Hello, World from Flask!" when accessed.

## Testing
Both examples include unit tests that can be run using pytest:
```bash
pytest tests/
```
